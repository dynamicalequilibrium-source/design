# 업무 바통

가상 업무자료로 디자인과 화면 이동을 검토하는 반응형 웹 시제품입니다.

## 실행

Node.js 22.12 이상을 권장합니다. 현재 Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev -- --port 3000
```

프로덕션 빌드: `npm run build`

## 구현된 화면과 흐름

- 업무문서: 카드·목록 보기, 분류, 검색, 정렬, 최근 본 문서, 즐겨찾기
- 문서 읽기: 목차, 절차, 문장별 질문 패널, 체크리스트, 샘플 근거 보기
- 질문함: 상태별 필터, 검색, 문서 연결, 질문 등록, 답변 등록, 해결 표시
- 내 업무: 할 일 체크, 내 질문, 최근 본 문서
- 공통: 알림, 프로필 메뉴, 모바일 내비게이션, 사용 가이드

질문·답변, 즐겨찾기, 최근 본 문서 및 체크리스트는 브라우저 localStorage에 저장합니다. 여러 사용자나 기기 간 동기화는 하지 않습니다. 브라우저 사이트 데이터를 삭제하면 샘플 초기 상태로 돌아갑니다.

모든 인물·업무·근거는 가상 예시입니다. 자료 업로드, 인수인계서 생성, AI 연결, 실제 파일 조회, 서버 인증·권한은 후속 범위입니다. `새 업무문서` 버튼에서 이 범위를 안내합니다.

React, Vite, Lucide를 사용합니다. 웹폰트를 불러올 수 없는 환경에서는 시스템 한글 글꼴로 표시합니다.
