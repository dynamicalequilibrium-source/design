# 업무 바통

업무자료에서 인수인계서를 만들고, 후임자가 읽고 질문하며 보완하는 경험을 검토하는 반응형 UX 시제품입니다. 생성 기능에 앞서 준비·열람·질문 흐름을 구현합니다.

## 실행

Node.js 22.12 이상을 권장합니다. 현재 Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev -- --port 3000
```

프로덕션 빌드: `npm run build`

데이터 모델 회귀 테스트: `npm test`

독립 실행 HTML 미리보기: `npm run build` 후 `npm run preview:export -- /원하는/경로/preview.html`. 서버 없이 브라우저에서 열 수 있으며 웹폰트 없이 시스템 글꼴로 표시합니다.

## 구현된 화면과 흐름

- 인수인계서: 만들기·이어서 읽기 진입, 카드·목록 보기, 분류, 정렬, 즐겨찾기
- 준비 화면: 업무 정보 → 샘플 자료 준비 → 고정 구성 미리보기, 준비 내용 저장·재개
- 읽기: 현재 단계·다음 행동·일정·담당자 요약, 목차, 읽기 위치 복원, 체크리스트, 샘플 Markdown 내보내기
- 문맥 질문: 문서·절 ID와 원문·적용 연도·샘플 버전 연결, 여러 답변과 답변별 댓글, 질문·답변 초안 복원
- 상태: 질문 해결과 답변 검토를 별도로 표시. 새 답변은 항상 미검토이며 다른 사용자의 질문 해결 조작은 제공하지 않음
- 검색: 문서와 질문·답변 검색, 관련 대화·절로 이동, URL과 브라우저 뒤로가기에서 검색 조건 복원
- 내 업무: 준비 중인 인수인계서, 내 질문, 최근 읽은 문서
- 공통: 내 질문의 답변 목록, 모바일 내비게이션, 키보드 조작, 포커스 복귀, 사용 가이드

질문·답변·댓글, 작성 초안, 준비 내용, 읽기 위치, 즐겨찾기와 체크리스트는 브라우저 localStorage에 저장합니다. 여러 사용자나 기기 간 동기화는 하지 않습니다. 저장 실패 시 오류를 표시합니다. 브라우저 사이트 데이터를 삭제하면 샘플 초기 상태로 돌아갑니다. 기존 질문 데이터는 원래 키에 남겨두고 새 모델로 복사합니다.

모든 인물·업무·근거는 가상 예시입니다. 준비 화면은 입력 정보를 저장하지만 입력한 자료를 분석하거나 인수인계서를 생성하지 않습니다. 샘플 미리보기는 입력과 별개의 고정 예시입니다. 파일 업로드, AI 생성, 실제 원문 조회, 편집·검토·게시·버전 재연결, 서버 인증·권한은 후속 범위입니다.

React, Vite, Lucide를 사용합니다. 웹폰트를 불러올 수 없는 환경에서는 시스템 한글 글꼴로 표시합니다.
