# 인수인계서 작성 및 게시

상단의 **새 인수인계서**에서 제목과 문단을 직접 입력하거나 원문을 가져옵니다. **초안 저장 → 검토 요청 → 검토 의견 입력 → 검토 완료 및 게시** 순서로 진행합니다. 수정이 필요하면 검토자가 **수정 요청**으로 초안으로 돌려보냅니다. 현재는 단일 공유 샘플 사용자로 작성과 검토를 모두 수행합니다. 정식 로그인이나 별도 검토자 권한을 제공한다는 뜻은 아닙니다.

문서는 SQLite에 저장됩니다. 작성 도중 입력은 같은 브라우저의 localStorage에 자동 보관됩니다. 실패하면 입력을 유지합니다. 다른 창에서 문서가 변경되면 저장을 거부하고 충돌을 알립니다. 이 경우 작성 내용을 복사한 뒤 편집창을 다시 열어 최신 문서에 반영하세요. 브라우저 초안은 서버 백업이 아닙니다.

## 원문 가져오기

TXT/Markdown(UTF-8 또는 CP949), 텍스트 PDF, DOCX를 지원합니다. 파일당 5MB, 추출 텍스트 6만 자, PDF 100쪽 이내입니다. 스캔 PDF의 OCR, HWP/HWPX, 이미지 분석은 지원하지 않습니다. DOCX 표는 텍스트로 추출하며 원본 서식은 보존하지 않습니다. 가져온 텍스트는 화면에서 확인한 뒤 **원문을 본문에 추가**하거나 **AI 초안 생성**을 실행합니다. 원본 파일은 보관하지 않으며 텍스트를 저장할 때만 문서 내용에 남습니다.

기존 문단의 제목과 텍스트를 편집할 수 있고 기존 표·인포박스·일정·체크리스트는 보존합니다. 표 셀과 인포박스 자체를 편집하는 전용 화면은 이번 범위에 포함하지 않았습니다. 기존 Q&A는 삭제하지 않습니다. 같은 문단에서 내용이 같은 문장은 질문 연결을 유지하고 바뀐 문장은 새 ID를 부여합니다. 이전 문장의 질문을 새 문장에 자동 연결하지 않습니다. 이전 Q&A 데이터는 `/api/state`에 보존되며 이전 원문은 버전 기록에서 열람할 수 있습니다. 이전 버전 Q&A 전용 열람 화면은 후속 과제입니다.

## AI 연결

OpenAI 호환 Chat Completions API를 사용합니다. Python 서버를 실행하는 환경에서 다음 변수를 설정하세요. `.env.local`이나 `.env.example`을 Python이 자동으로 읽지는 않습니다.

```sh
export BATON_AI_BASE_URL=http://127.0.0.1:12345/v1
export BATON_AI_MODEL=google/gemma-4-e4b
# 인증이 필요한 서버만:
# export BATON_AI_API_KEY=...
python -m uvicorn server.app:app --host 127.0.0.1 --port 8000
```

LM Studio는 Python API 서버와 같은 PC에서 실행하거나 접근 가능한 모델 서버 주소를 지정해야 합니다. 브라우저가 실행되는 PC의 localhost와 원격 Python 서버의 localhost는 다릅니다. 생성은 서버에서 호출하며 API 키는 브라우저로 전달하지 않습니다. 원문은 설정한 모델 서버로 전송됩니다.

제공 자료에서 업무 개요·절차·일정·주의사항·미결 업무를 JSON 구조로 생성합니다. 자료에 없는 내용은 확인 필요로 표시하도록 지시하며 실제 사실 정확성을 보장하지는 않습니다. 생성 결과는 편집창에 추가되고 사용자가 저장하기 전에는 DB에 문서를 생성하지 않습니다. 미설정, 연결 실패, 잘못된 JSON, 응답 잘림은 오류로 표시하고 원문과 기존 본문을 유지합니다. 현재 환경에는 실제 모델 연결이 없으므로 실모델 품질·응답시간은 검증하지 않았습니다.

## 버전과 내보내기

모든 초안 저장과 상태 전환은 새 리비전으로 기록합니다. **버전 기록**에서 이전 원문과 검토 의견을 볼 수 있습니다. 기존 게시본을 수정하면 현재 문서는 초안으로 바뀌고 이전 게시본은 기록에서 유지됩니다. 게시본과 진행 중 초안을 동시에 별도 문서로 보여주는 기능은 없습니다.

현재 문서와 기록의 버전은 Markdown으로 다운로드할 수 있고 현재 문서는 JSON 다운로드도 지원합니다. **인쇄 / PDF**에서 브라우저의 PDF 저장을 사용합니다. JSON은 내보내기 용도이며 JSON 복원·가져오기는 지원하지 않습니다. Markdown에는 제목·요약·본문·표·각주를, JSON에는 문서 전체 구조를 포함합니다. Q&A는 문서 내보내기에 포함하지 않습니다.
