# 인수인계서 중심 UX 개선

2026-10-20

제품의 핵심은 업무자료로 쓸 만한 인수인계서를 만드는 능력이다. 현재 단계는 생성 엔진의 구현에 앞서 사용 경험을 검토하는 시제품이다. 위키와 질문·답변은 생성된 인수인계서를 읽고 보완하는 방식이다.

## 이번 변경

- 첫 화면을 ‘인수인계서 만들기 / 이어서 읽기 / 인수인계서 모아보기’로 구성했다. 기존 녹색·주황색 브랜드를 유지한다.
- 만들기 버튼을 안내 팝업에서 별도 준비 흐름으로 연결했다. 업무 정보와 샘플 자료 선택을 저장하고 재개할 수 있다. 고정 미리보기와 실제 AI 생성의 차이를 단계마다 명시한다.
- 읽기 첫 화면에 현재 단계·다음 행동·가까운 일정·협의할 사람을 배치했다. 업무별 가상 내용은 여섯 문서마다 다르게 구성한다.
- 목차와 명시적인 문단 질문 버튼을 제공한다. 본문 클릭이나 드래그를 가로채지 않는다. 질문 패널에는 해당 문맥과 버전·연도를 표시한다.
- 질문은 문서 ID와 안정적인 절 ID에 연결한다. 대상 원문을 스냅샷으로 저장하고 해당 문구만 강조한다. 정밀한 임의 문장 범위 선택은 다음 단계다.
- 1100px 이하에서는 본문과 질문을 한 열로 전환하고 인용문과 ‘읽던 본문으로’를 유지한다. 큰 화면에서는 본문과 대화를 나란히 보여준다. 닫으면 원래 질문 버튼으로 초점이 돌아간다.
- 질문 해결은 질문의 상태, 검토 배지는 답변의 상태로 분리한다. 새로운 답변은 미검토로 표시하며 질문을 해결해도 검토 여부는 바뀌지 않는다.
- 질문·답변 작성 내용은 문서/절 또는 질문별로 보존한다. 준비 단계와 읽기 위치도 재접속 후 복원한다.
- 검색은 문서와 연결된 질문·답변을 포함하며, 본문 또는 대화에서 일치하면 관련 절·질문을 함께 연다.

## 경계

서버·AI·파일 파서·실제 게시 기능을 추가한 변경이 아니다. 미리보기나 가상 근거를 실제 분석 결과로 표현하지 않는다. 다음 단계는 샘플 한 업무에서 생성 품질을 검증할 자료·정답 목록·출처 구조를 준비하는 것이다.
