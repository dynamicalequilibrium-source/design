# 알려진 한계

이 변경은 첫 서버 저장 기능이며 설계계획서 v0.4의 전체 MVP가 아니다.

- 단일 샘플 사용자와 공유 문서만 제공한다. 세션/CSRF 검사와 별개로 문서별 ACL·역할 전환·로그인 만료·정식 인증은 미구현이다. localhost에서만 실행한다.
- 기존 질문 UI는 모달이다. 읽기 중심 목차/본문/옆 패널의 최종 배치는 후속 작업이다. 본문 글자 크기·전체 키보드 접근성·200% 확대·초점 표시의 전수 검증은 하지 않았다.
- 문장 기반 질문만 서버에서 검증한다. 표 셀의 합성 문장 질문, 문단 내 임의 부분 범위 선택, NFC 정규화 및 UTF-16 범위 변환은 후속 작업이다. 검증되지 않는 인용은 저장하지 않는다.
- 문서 버전은 고정이다. 초안 편집·충돌 비교·검토·게시·연결 재지정·본문 반영·질문 수정/보관/해결 변경·답변 수정은 아직 지원하지 않는다.
- 자유 입력 근거는 ‘확인 필요’ 메모다. 기존 샘플 근거도 실제 파일을 열거나 존재·인용을 검증하는 기능은 없다.
- 업로드·형식별 파서·작업 프로세스·AI·통합 검색·알림·내 업무·내보내기·백업/복원은 이번 서버 변경 범위 밖이다. 기존 화면의 정적 안내나 예시 검색은 해당 서버 기능 완료를 뜻하지 않는다.
- 공감/추천은 이번 변경에서 비활성화했다. 샘플 데이터에 남은 순위·채택 정보는 최종 UX 검토가 필요하다.
- 브라우저 초안은 같은 기기/브라우저에만 존재하고 사이트 데이터 삭제 시 사라진다. 댓글 작성 초안, 재접속 후 미확정 요청 키 복원, 다중 탭 간 초안 충돌 해결은 제공하지 않는다.
- 클라이언트 목록은 로드 시 받아온 스냅샷이다. 다른 브라우저의 새 질문/답변은 새로고침 후 보인다.
- SQLite 작업은 작은 로컬 샘플을 전제로 한다. 대용량 성능, 다중 프로세스 동시성, 세션 만료/청소, 백업 복구는 별도 검증이 필요하다.
