# 현재 구현 한계

- AI 인수인계서 생성은 미구현이다. 준비 화면은 업무 정보와 샘플 선택을 로컬에 저장한다. 구성 미리보기는 고정된 보조사업 예시다.
- 원문 파일 업로드·분석·다운로드와 실제 근거 위치 확인은 연결되지 않았다. 근거 창은 가상 인용임을 표시한다.
- 인수인계서 여섯 개는 읽기 전용 샘플이다. 문서 편집·게시·검토 승인·본문 반영·과거 버전 조회는 미구현이다. v1.3은 샘플 버전 표기다.
- 질문 대상은 안정적인 절 ID와 해당 절의 대표 인용문이다. 임의 문장 범위, 문자 오프셋, 편집 후 재연결은 지원하지 않는다.
- 질문 해결과 답변 검토는 데이터상 분리했다. 샘플 답변의 검토 배지만 있으며 실제 검토자 계정 전환이나 검토 승인 기능은 없다.
- 모든 사용자 작성물은 이 브라우저의 localStorage에 저장한다. 동기화·서버 인증·문서별 권한은 없다. UI에서 본인 질문의 해결 버튼만 제공하는 것은 서버 권한 검증을 대신하지 않는다.
- 읽기 위치는 절 단위다. 문장 안의 정확한 읽기 위치나 브라우저 종료 후 목록 스크롤까지 복원하지는 않는다.
- 기존 데이터 키는 삭제하지 않고 새 질문 모델로 복사한다. 버전이 없는 구형 ‘답변 등록’ 데이터는 미검토 답변으로 이관한다. ‘해결됨’을 검토 완료로 해석하지 않는다.
- 질문·답변 초안은 저장하지만 작성 중 댓글은 현재 화면 상태만 유지한다.
- 앱 알림은 내 질문의 답변 목록을 보여준다. 읽음 상태, 서버 알림이나 외부 발송은 구현하지 않았다.
- WCAG 전체 준수 인증이나 스크린리더 사용성 검증을 완료한 것은 아니다. 키보드와 반응형에 대한 범위 검증 결과는 test-results.md에 기록한다.
