# 테스트 기록 · 2026-10-22

환경: Linux, Node.js 24.19.0, Python 3.12.14, FastAPI 0.141.1, Vite 8.3.5. Chromium + Python Playwright로 로컬 API/Vite를 검사했다. 가상 자료와 분리한 테스트 DB만 사용했다.

| 검증 | 결과 |
|---|---|
| `npm run lint` | TypeScript 오류 없음 |
| `npm run build` | 프로덕션 번들 생성 성공 |
| `npm run test:api` | 7개 API 테스트 통과 |
| `python tests/browser_flow.py` | 브라우저 흐름 통과 |

## API 검증 범위

1. 질문 등록 후 새 DB 연결/다른 샘플 세션에서 재조회, 같은 문장의 여러 질문 보존, 원문·버전·코드 포인트 범위 기록.
2. 같은 요청 키 재시도는 같은 결과, 다른 내용은 409.
3. 병렬 요청 키 재시도 시 같은 결과. ASGI 검사이며 실제 다중 프로세스 부하 테스트는 아니다.
4. 익명 상태 조회/변경은 401, CSRF 누락은 403.
5. 잘못된 인용·문단은 409, 없는 문서는 404.
6. 답변·댓글 저장, 검토 배지 자동 부여 없음, 자유 입력 근거 미검증 처리.
7. 빈 제목·없는 질문 차단.

## 실제 브라우저 검증 범위

- 더블클릭으로 텍스트를 선택할 때 질문창이 열리지 않음.
- 질문 제목·내용 작성 중 새로고침 후 해당 문장에서 초안 복원.
- 저장 요청을 강제로 실패시킨 뒤 오류 표시와 입력 유지, 재시도 성공.
- 질문 등록 후 연결된 질문 선택 목록에 표시.
- 답변·사용자 입력 근거·댓글 작성 후 서버 저장, 새로고침 후 재조회.
- 닫기/Escape 뒤 선택 문장으로 키보드 초점 복귀.
- 1440px 및 390px 화면에서 흐름 수행. 390px 가로 페이지 넘침 없음.
- 검사 중 미처리 브라우저 런타임 오류 없음.

전체 T01~T12, 역할별 문서 접근권한, 근거 원문 검증, 버전 편집/재연결, 파일 파싱, AI 품질, 백업 복원 및 성능 목표는 미검증/미구현이다. 따라서 전체 MVP 완료로 판정하지 않는다.

초기 설치에서 Vite/esbuild peer 충돌을 발견해 의존성을 맞췄다. 최초 브라우저 검사에서 헤더 가로 넘침을 발견해 수정 후 다시 통과했다. Vite의 향후 native config loader에 관한 기존 `__dirname` 경고는 빌드를 차단하지 않는다.
